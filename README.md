Tutorial Summary (Week 1–10)

Week 1 – Getting Started with Codespaces via GitHub

This tutorial introduces GitHub repository creation and GitHub Codespaces. The activities include creating a repository, adding a README file, selecting Java as the project language, and setting up the development environment.

The practical exercise involves creating a tutorial_1 directory and writing Java files such as HelloWorld.java and StudentGrade.java. The tutorial also introduces basic Git commands for tracking and uploading changes.

Key learning outcomes:

Create and organize a GitHub repository.
Set up a Java development environment.
Create and manage Java source files.
Understand basic Git version-control commands.
Week 2 – Coding in Java Programming Language

This tutorial focuses on Java classes, objects, constructors, attributes, and methods. Students create a Student class and a main program to demonstrate how student information can be stored and displayed.

The exercise introduces the organization of Java programs into separate source files and demonstrates how objects can use methods to display information.

Key learning outcomes:

Understand Java class and object concepts.
Declare attributes and constructors.
Create methods to display information.
Organize a Java project into multiple files.
Week 3–4 – Classes, Inheritance, and Method Overriding

These tutorials introduce object-oriented modeling through a scenario involving different types of people at a university. The program represents a general Person class and specialized Student and Lecturer classes.

The exercise demonstrates inheritance, constructors, methods, and method overriding. The expected output shows different introductions for a person, a student, and a lecturer.

Key learning outcomes:

Design classes based on a real-world scenario.
Use inheritance to extend a parent class.
Apply constructors and the super() keyword.
Override methods to provide specialized behavior.
Understand how inheritance supports code reuse.

How to Run the Projects

Prerequisites

Access to the GitHub repository.
Git, if working locally.
A Java Development Kit (JDK), if compiling and running the projects locally.
A Java-compatible development environment, such as GitHub Codespaces or an appropriate code editor.
Step 1: Clone the Repository

Open a terminal and run:


bash
git clone <repository-url>
Replace <repository-url> with the URL of your GitHub repository.

Step 2: Navigate to the Repository


bash
cd <repository-folder>
Replace <repository-folder> with the name of your project directory.

Step 3: Open the Required Tutorial

Navigate to the folder containing the exercise you want to run. For example:


bash
cd tutorial_1
Step 4: Compile the Java Program

If the program is named HelloWorld.java, compile it using:


bash
javac HelloWorld.java
Step 5: Run the Program


bash
java HelloWorld
Use the appropriate class name for the program you want to execute. If a tutorial contains multiple Java files, compile the required files together or compile the main file with its dependencies as appropriate.

Git Command-Line Tips

The following commands are useful for managing the repository and submitting completed tutorial work.


Command	Description
git init	Initializes a new Git repository.
git status	Displays the current repository status.
git add file_name	Stages a specific file for committing.
git add .	Stages changes in the current directory.
git commit -m "Your message"	Records staged changes in a commit.
git push	Uploads committed changes to the remote repository.
Example Git Workflow

After completing a tutorial, use the following commands:


bash

git push
This workflow helps maintain a record of completed work and keeps the remote GitHub repository updated. The initial push may require additional remote or branch configuration, depending on how the repository was created.
